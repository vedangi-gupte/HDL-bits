# HDLBits Solutions (Verilog)

My solutions to the [HDLBits](https://hdlbits.01xz.net/) problem set, a collection of practice problems for digital design in Verilog. I built these up over 150+ commits.

## Contents

| Folder | Topics |
|---|---|
| `Verilog Language` | Basics, vectors, modules, procedures, and other language features |
| `Circuits` | Combinational logic, sequential logic (flip-flops, counters, shift registers, FSMs), and larger circuits |
| `5. verification: writing testbench` | Writing testbenches: clocks, stimulus, and self-checking tests |

## Skills practiced

- Synthesizable RTL coding in Verilog
- Finite state machine design (Moore and Mealy)
- Combinational and sequential datapath design
- Testbench writing and simulation-based debugging
